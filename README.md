# XOMA MUSIC BOT

Telegram-бот на Python для:
- поиска аудиозаписей через официальный VK API (`audio.search`), если VK разрешает этому токену такой метод;
- выдачи прямой ссылки на страницу трека во VK;
- личной библиотеки файлов, которые пользователь сам отправил боту и имеет право хранить/передавать.

## Важное ограничение

Бот **не скачивает аудиопотоки из VK, не обходит авторизацию, DRM, платные ограничения или ограничения API**. В VK API доступ к аудиометодам может быть ограничен или недоступен для конкретного приложения/токена. Если VK возвращает ошибку доступа, это не ошибка Telegram-бота: нужно получить разрешённый доступ VK либо использовать ссылки и собственные аудиофайлы.

## 1. Создай Telegram-бота

1. Открой Telegram и найди `@BotFather`.
2. Отправь `/newbot`.
3. Задай имя `XOMA MUSIC BOT` и username, заканчивающийся на `bot`.
4. Скопируй токен. Никому его не показывай.

## 2. Подготовь VK API

1. Создай приложение VK в кабинете разработчика VK.
2. Получи токен только официальным OAuth-процессом и только с нужными разрешениями.
3. Убедись, что VK разрешает приложению использовать `audio.search`. Наличие токена само по себе не гарантирует доступ к аудиометодам.
4. Не используй чужие токены и не вставляй токен в публичные чаты.

Если VK не предоставляет доступ к `audio.search`, бот всё равно будет работать как Telegram-библиотека аудиофайлов и обработчик VK-ссылок.

## 3. Установка на Windows

Установи Python 3.11 или новее с сайта https://www.python.org/downloads/ и отметь **Add Python to PATH**.

Распакуй архив, открой папку `xoma_music_bot`, затем в адресной строке Проводника напиши `cmd` и нажми Enter.

Выполни по очереди:

```bash
python -m venv .venv
.venv\\Scripts\\activate
pip install -r requirements.txt
copy .env.example .env
```

Открой файл `.env` в Блокноте и вставь токены:

```env
BOT_TOKEN=твой_токен_от_BotFather
VK_TOKEN=твой_разрешённый_VK_API_токен
VK_API_VERSION=5.199
DB_PATH=xoma_music.db
```

Сохрани файл. Запусти:

```bash
python bot.py
```

Открой своего бота в Telegram и нажми **Start**.

## 4. Команды бота

- `/start` — запуск и описание.
- `/help` — инструкция.
- `/library` — список твоих файлов.
- `/library 1` — повторно отправить сохранённый файл с номером 1.
- Обычный текст — поиск во VK.
- Ссылка VK — кнопка открытия ссылки.
- Аудио/аудиодокумент — сохранить в личную библиотеку.

## 5. Бесплатный режим

Для бесплатного запуска бот работает, пока запущен компьютер и окно терминала не закрыто. База `xoma_music.db` хранится рядом с кодом. Не удаляй её, если хочешь сохранить библиотеку.

## Безопасность

- Не публикуй `.env`.
- Если токен Telegram случайно утёк, отзови его через BotFather и выпусти новый.
- Не загружай в библиотеку материалы, на которые у тебя нет прав.
